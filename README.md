# Portfolio

Personal portfolio site built with Astro and GSAP.

## Run it

```
npm install
npm run dev
```

The dev server runs at http://localhost:4321. `npm run build` outputs a static site to `dist/`.

## Editing content

Name, role, contact links, projects and skills all live in `src/data/site.ts`.

## Fonts

Sofia Sans Condensed (headings) and Spline Sans Mono (body), installed from `@fontsource`.
